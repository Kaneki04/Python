# Python projects

A collection of small Python projects and experiments built while learning and exploring automation, language tools, APIs, and scientific computing.

## Included projects

### Spotify
Scripts using the Spotify Web API for working with saved tracks, plus local audio-processing utilities.

Credentials are intentionally read from environment variables. Before running the Spotify scripts, set:

```bash
export SPOTIPY_CLIENT_ID="..."
export SPOTIPY_CLIENT_SECRET="..."
export SPOTIPY_REDIRECT_URI="http://localhost:5000/callback"
```

### TraductorAudioRuso
An early speech-recognition and translation experiment that extracts audio from a video, transcribes it, and translates the recognized text.

### calcusv2
A collection of small physics/calculation exercises.

## Note

These projects span different stages of my Python learning and are kept primarily as a record of experimentation and progression.
